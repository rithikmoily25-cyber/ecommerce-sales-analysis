# ecommerce-sales-analysis
Project Overview

An E-Commerce Sales Analysis project using Microsoft Excel to clean, analyze, and visualize retail sales data.

Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Excel Slicers
* Excel formulas

Work Completed

* Explored the retail sales dataset.
* Identified missing values.
* Removed exact duplicate records.
* Created sales KPIs.
* Analyzed sales by store, product, department, and payment method.
* Created a monthly sales trend chart.
* Built an interactive Excel dashboard using slicers.

Project Status

Excel analysis and dashboard completed.
## Key Business Questions

1. What are the total sales?
2. Which products generate the highest sales?
3. Which months have the highest sales?
4. Which stores perform best?
5. Which payment method is most popular?
